# Kebijakan Privasi — AWALI (Absensi WAjah dan LokasI)
**Versi M01 · Oktober 2026** *(Fase Penyimpanan Lokal — Belum Ada Transmisi Cloud)*  
**Penanggung jawab:** 2300016104_Andang Purwanto

---

Kami di tim pengembang **AWALI** sangat menghargai dan berkomitmen menjaga privasi serta keamanan data pribadimu. Dokumen kebijakan privasi ini ditulis dengan bahasa yang sederhana agar kamu memahami bagaimana data presensimu dikelola.

### 1. Data yang Kami Simpan
Aplikasi AWALI hanya mengumpulkan dan memproses data yang benar-benar dibutuhkan untuk pencatatan kehadiran:
- **Identitas Akun:** Nomor Induk Pegawai (NIP) dan nama lengkap untuk memastikan data kehadiranmu tercatat atas namamu.
- **Data Lokasi (GPS):** Koordinat posisi perangkatmu saat kamu menekan tombol presensi, semata-mata untuk memverifikasi bahwa kamu berada di area kantor yang ditentukan. Kami **tidak melacak lokasimu di latar belakang** setelah presensi selesai.
- **Foto Verifikasi Wajah:** Gambar wajah yang kamu ambil saat melakukan presensi masuk atau pulang untuk memastikan bahwa kehadiran dilakukan olehmu sendiri.
- **Kredensial Keamanan:** PIN aplikasi yang kamu buat untuk melindungi akses ke aplikasi di ponselmu.

### 2. Di Mana Data Disimpan
Pada versi M01 ini, **seluruh datamu disimpan secara lokal di dalam ponselmu sendiri**:
- Informasi sensitif (seperti PIN dan sesi login) diamankan menggunakan teknologi enkripsi perangkat keras bawaan ponsel (*Android Keystore / iOS Keychain*).
- Kami **belum menghubungkan aplikasi ke server atau cloud eksternal**. Tidak ada data pribadimu yang dikirimkan ke internet pada versi ini.

### 3. Siapa yang Bisa Melihat Datamu
- **Hanya Kamu:** Karena data tersimpan di perangkat lokalmu, hanya kamu yang dapat melihat rekaman riwayat presensi di layar aplikasimu.
- Kami tidak pernah menjual, menyewakan, atau membagikan data pribadimu kepada pihak ketiga, pengiklan, atau pihak lain yang tidak berwenang.

### 4. Hak-Hakmu atas Data Pribadi
Sesuai dengan UU Pelindungan Data Pribadi (UU PDP), kamu memiliki hak penuh untuk:
- **Melihat & Memeriksa:** Kamu dapat melihat seluruh riwayat catatan presensimu kapan saja di aplikasi.
- **Meminta Koreksi:** Jika terjadi kendala deteksi lokasi atau kamera, kamu dapat mengajukan laporan koreksi presensi kepada bagian administrasi/HRD.
- **Menghapus Datamu:** Kamu dapat menghapus seluruh riwayat presensi dan data login lokalmu kapan saja melalui menu **"Hapus Seluruh Data"** di aplikasi secara permanen.

### 5. Perubahan Kebijakan di Masa Depan
Jika di kemudian hari (pada Milestone integrasi sistem M05) aplikasi menambahkan fitur sinkronisasi basis data cloud terpusat ke server kantor, kamu akan mendapatkan pemberitahuan pembaruan kebijakan ini secara transparan sebelum fitur tersebut diaktifkan.
